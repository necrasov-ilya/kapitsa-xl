# Kapitsa XL

Форк основан на Kapitsa 0.2.0, исходный коммит `4e0154f`.
Поддержка 122B проверяется на MacBook Pro с M1 Max, 24 ядрами GPU, 64 ГБ памяти и macOS 27.0.1.

## Что изменено

- Импорт и вычисления с экспертами IQ3_XXS сохраняют исходные квантованные веса
- Допустимое отношение числа голов внимания к числу голов ключей увеличено до 16
- Размер промежуточного слоя эксперта увеличен до 4096
- При превышении общего буфера активаций на 7168 чисел используется обработка по одному эксперту
- Добавлены проверки ядер на размерах слоёв 122B

## Сборка и запуск

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 8 --target kapitsa
build/kapitsa import /path/to/Ornith-1.5-122B-AD-IQ3_XXS-IQ2_S.gguf --name ornith-122b
NI_NO_MTP=1 build/kapitsa serve --model ornith-122b --slots 1 --context 8192 --prefill-chunk 256 --spec 0 --dflash none
```

`KAPITSA_HOME` позволяет выбрать отдельный каталог моделей. Импорт использует около 8,22 ГБ дополнительного места при
клонировании исходного GGUF средствами APFS на том же томе. На другом томе требуется место для полной копии.
Для проверенного файла размером 47,64 ГБ сервер выделяет около 46,8 ГБ вместе с рабочими буферами и состоянием одной беседы.
Загрузка занимает около 21 секунды. На двух ответах по 128 токенов измерены 19,8 и 20,0 токена/с.
Обработка запроса на 2650 токенов заняла 14,56 секунды, около 182 токенов/с.
Это предварительные измерения конкретного файла и режима запуска, без сравнения с другими движками.

Проверен обычный режим генерации. MTP и дополнительные модели для ускорения генерации пока не проверены.
Наличие поддержки архитектуры не гарантирует размещение любого варианта 122B в 64 ГБ памяти.

## Проверки вычислений

`bench_moe_iq --validate --fmt iq2s:iq3xxs` проверяет новые вычисления относительно контрольной реализации на CPU.
`--xl` задаёт размеры скрытого слоя 3072, эксперта 1024 и восемь выбранных экспертов.
Проверены одиночные запросы, совместная обработка нескольких строк и предварительная обработка контекста.
Проверки выполнены с `MTL_SHADER_VALIDATION=1 MTL_DEBUG_LAYER=1`.

`moe_slot_check` сравнивает буфер на 9216 активаций с контрольным вычислением на CPU.
При 4608 активациях дополнительно проверяется точное совпадение с прежним ядром.
Для нового ядра включалась проверка Metal. Для сравнения с прежним ядром проверка отключалась,
поскольку её служебная память превышает предел 32 КиБ у прежнего ядра.
Все запуски GPU должны удерживать блокировку `~/.cache/nace-gpu.lock`.
